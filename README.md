# Noticias EL PAÍS
Independent Android RSS reader for EL PAÍS.

RSS: https://feeds.elpais.com/mrss-s/pages/ep/site/elpais.com/portada

Search, refresh, sharing, article view, offline cache, passive NetworkObserver and full connectivity diagnostics. The current DNS-first/HTTPS/ICMP connectivity helper from the referenced gist is vendored under third_party/connectivity and adapted into the app package.

Release 1.2.0 adds the updated connectivity implementation, a refreshed launcher icon, and progressive infinite scrolling through the RSS results.

This is not an official EL PAÍS application.
